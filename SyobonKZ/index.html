SyobonKZ is my own continuation of the OpenSyobonAction dead project, im trying to fix bugs and improve things to match the original games (and also fix some annoying things from the original games)

Some improved things are:
• Windows, Linux, macOS, Android and Web Browser ports!
• SDL3 support
• Fullscreen
• Fixed missing sprites
• Fixing mismatches with the original Syobon Action 1 and 2!
• Code being improved continuously!
• Plans to support Syobon Action 3, 4 & 5 (only if i have time and motivation, but contributions are welcome)!
• And others that i dont remember now :0!
