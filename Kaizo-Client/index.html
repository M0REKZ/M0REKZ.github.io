+KZ custom client for DDNet/Teeworlds
(no, this is not another T-Client fork)

While other clients are focused in rainbow and colorful things, this client adds useful gameplay features, of course i still add some visual things if i randomly want them, but it is not the main focus here.

Also since usually i play with 200 ping i tend to add features to fight against the lag.

Main Features
  • Smooth Moving Tiles collision prediction (currently using Kaizo Network collision system)
  • Adjustable map download speed (requires good connection)
  • Show Grenade and Laser path
  • Predict DDNet teleports with 1 exit
  • Better Antiping (from T-Client)
  • Bindwheel (from T-Client)
  • Show communities made by the community in the server browser (unlike DDNet xd)
  • Fast Input (from T-Client but with some fixes)
  • ChaiScript support (what is ChaiScript?)
  • Better Teeworlds 0.7 support than DDNet
  • Prediction for Pointer's TWPlus
  • Ping circles (from T-Client and Kaizo Network)
  • Extremely ugly Kaizo Client settings tab
  • Try to know which custom client are other players using
  • Try to know if other players are checking the menu
  • Some Discord support
  • Zoom in old non-DDNet mods where it is not actually a strong unfair advantage so they dont ban this client (like 'Race' and 'Monster')
  • Rotating Hammer (not actually from T-Client xd)
  • Reply when tabbed out (was it from T-Client or Chillerbot-ux? i forgot xd)
  • No voice chat support
  • Some other features that some people say its cheating and other people dont care so idk enable them at your own risk
  • There are so many features that they dont even fit in this list :0


Features for Kaizo Network
  • Smooth Moving Tiles collision prediction
  • Use Kaizo Network physics in Kaizo Network servers
  • Prediction for Kaizo Network maps
  • Open and Save Kaizo Network maps
  • Show Kaizo Network entities with custom sprites
