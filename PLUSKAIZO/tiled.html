How to create levels using Tiled


PLUSKAIZO currently has no Level Editor (I am working on one), however if you really want to create your level, you will need to use a external level editor named "Tiled"

Setting up the editor:

  • Step 1: Download Tiled: https://www.mapeditor.org/
  • Step 2: Create a new Tiled Project
  • Step 3: Edit Tiled Preferences (IMPORTANT):
    On Export Options, set "Resolve object types and properties" to True
  • Step 4: Now time to make levels...
    You will need to download this file and extract its content:
    Download Tileset and Entities
    Put the extracted files on the Project folder
  • Step 5:Add the two tilesets to the Tiled Project

Mapping:

To Start Mapping you need to know the level structure for Tiled format

A PLUSKAIZO Level in Tiled format has the next folder structure:
  • LEVEL (Folder with level name)
    • section_1.tmj
    • section_2.tmj
    • section_3.tmj
    • section_x.tmj

So you need to create a folder in your project with your level name, and inside THAT folder create a "section_1.tmx" file (DONT CREATE IT WITH THE .tmj FORMAT)

Now we want to add a layer to our level, that is done by right-clicking inside the "Layers" box, adding a Tile Layer, adding a Objects Layer... and then selecting both layers, right-clicking them and adding them to a group.....

WHY??!?? Due to the way Tiled works, we can not put entities and tiles in the same layer, so PLUSKAIZO will understand Groups of Layers as actual Layers, note that on those Groups you must only add one Tiles Layer and one Objects Layer, otherwise things wont work...

Now you can start mapping:
To place TILES, select the Tile Layer from the group and the grass.tsx tileset.
To place ENTITIES, select the Object Layer from the group and the entities.tsx tileset.

Exporting the map:


To play the map in PLUSKAIZO, you must EXPORT it as a .TMJ file, dont SAVE it as .TMJ format, EXPORT it, there is a difference when using any of the two options, and "SAVING" it will not store information that the game needs to understand the level...

Why things are this way? I dont know, ask Tiled developers why they did things this way

Now that you exported the section_1.tmx as section_1.tmj and have that section inside a folder with your level name, put that folder in the Levels folder which is located at:
C:/Users/"YOURNAME"/PLUSKAIZO/data/levels/

Now you can open PLUSKAIZO and select the level to try it, if you can not play... maybe you did something wrong...
